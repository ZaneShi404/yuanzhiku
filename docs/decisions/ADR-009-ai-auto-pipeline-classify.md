# ADR-009：AI 自动流水线与自动分类

状态：接受。

v1.4.0 的四项关联决策：

1. **建议自动写入、只填空缺**：AI 产出的领域/体裁/标签建议（视频摘要、文档/粘贴分类）在作业成功后自动写入来源元数据，不再仅嵌入标记等待人工采纳；覆写规则为只填空缺——领域/体裁仅在当前为空时写入、标签取并集合并、用户已填字段绝不覆盖，用户可事后在"编辑元数据"中修改；实际写入记 `ai_classify_applied` 审计事件（仅字段与数量，不含内容）。摘要建议标记新增 `applied` 字段，前端据此对旧摘要保留手动采纳按钮（幂等）。
2. **自动分类范围含文档与粘贴**：文档/粘贴的解析正文（截断至前 8000 字符）也发理解组模型分类（新增 `source_classify` 作业类型与 `MediaAiPort.classify` 端口，约束 JSON、值域强制收敛到分类清单）；图片无正文文本，不分类。用户已接受该出网面，威胁模型与 REQ-052 同步修订。
3. **导入页分类选择收起**：领域/体裁选择区折叠为可选披露（默认收起可跳过，想手选可展开），选择器行为不变。
4. **自动串联流水线**：`ai_auto_pipeline` 总开关（默认开，经设置页或 `PUT /settings/ai` 调整）启用且对应分组已配置时，`video_analyze` 成功自动串联 `video_transcribe`→`video_summarize`，文档/粘贴 parse 成功自动入队 `source_classify`；同版本同类作业已排队/运行中不重复入队，未配置对应分组时不入队（也不产生 blocked 作业）。

后果：配置 AI 后导入即可得到转写/摘要/分类全链路产物与初版分类元数据，人工干预减到最少；`source_classify` 与转写/摘要同属附加产物，失败/取消不降低版本完整性与来源处理状态；关闭总开关即回到逐作业手动触发，出站面随之收回显式触发。（`REQ-051`、`REQ-025`、`REQ-033a`）
