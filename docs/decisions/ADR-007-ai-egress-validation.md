# ADR-007：AI 出站标准校验与第二网络出口

状态：接受。

引入可配置媒体 AI 后系统出现第二个网络出口（第一个是 `REQ-047` 受限下载通道）：音频分块、关键帧图片与转写文本会发往用户配置的外部端点。下载通道的回环过滤代理以平台注册域清单为语义，不适用于用户自选端点，因此不复制该机制，而采用统一 base_url 校验：仅 HTTPS、仅公网主机、无 userinfo、不超过 2048 字符，拒绝消息不含 URL 内容；发送仅发生在用户逐视频显式触发的作业中，默认关闭即零出站流量；AI 调用错误一律脱敏为不含 URL、密钥或响应正文的中文短消息。后果：第二出口被显式配置与用户动作双重门控，错误面不泄露端点与密钥，威胁模型按独立出口登记。（`REQ-052`、`REQ-051`）
