# ADR-008：检索过滤重构：分类标签退出全文

状态：接受。

旧实现把固定分类与标签 token 拼入全文语料：英文分类 token 对中文用户不可搜且制造噪声命中，视频容器元数据模板（`ffmpeg-local` representation）同样污染全文。决定全文语料只含标题、作者、备注与正文类 representation 文本，分类（领域/体裁）与标签仅作结构化过滤；`ffmpeg-local` 元数据模板不进入全文（图片 `pillow-local` 中文元数据摘要保留）。检索过滤新增领域（重复参数、OR 语义、`_none` 哨兵匹配未分类）、体裁（单值、`_none` 匹配无体裁）与 `topic_id`（仅过滤来源分支）。后果：字面子串检索语义更干净，仍不宣称语义检索；旧 `category` 过滤参数移除，构成破坏性 API 变更。（`REQ-024`、`REQ-050`）
