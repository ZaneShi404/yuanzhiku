# ADR-013：帧级画面理解——联络表兜底与可选增强

状态：接受（v1.7，2026-09-04 用户裁定，对 ADR-011 偏差 B 的有意识修订）。

摘要作业补充理解从两级改为三级（`REQ-057`、决策 25/26/27）：① 整片直送维持
主路径（稀疏帧丢运动与帧间文字，信息量严格劣于整片）；② 帧理解兜底——直送
不可行/失败且 `ai_video_frames_fallback=on`（默认 on，用户审定 D-b：仅在用户
已授权 AI 的直送失败场景触发、帧字节远小于直送）且适配器声明 `image_input`
可行时，构建关键帧联络表（≤`ai_video_sheet_frames`（默认 24，用户审定 D-c）
格瞬态缩略图网格、单格 ≤320px、格子 1..N 编号，全部位于作业 staging、绝不入
`video_frames`/artifact）+ 格子时间窗对照 + 转写节选，一次多模态调用同时产出
「值得关注时刻」与带时间定位的画面理解条目（决策 25 联络表机制，替代「文本
LLM 报时间戳→再抽帧→再理解」三段式）；③ visual_gap 收窄为直送与帧理解皆不
可行。另设 `ai_video_frames_enrich`（默认 off）允许「转写完整」场景也做画面
理解增强（tier 1.5，标记 enriched）。作业形态为摘要作业内分支（决策 27，用户
审定 D-a）而非独立作业+两父汇合——兜底/增强触发条件（直送是否失败、完整性判
定结果）只在摘要运行中可知，独立作业要么 Always-on 产生无谓调用、要么无法预
知触发；分支式零新增作业 kind 与链式机制，`REQ-033a` 语义自然覆盖。条目落
独立 `visual_understanding` 表示（父链挂 transcription、逐条 `video_time_range`
证据、进入检索）；模型引用越界格子号的条目一律丢弃、有效条目为零按失败处理，
绝不伪造。本裁定修订 ADR-011 偏差 B（2026-08-16 彻底移除关键帧视觉路径）的
「彻底」：帧理解作为兜底与增强回归，直送主路径地位不变——修订理由是 v1.5 发
布后实践暴露直送不可行场景（MiMo base64 ≈37MB 上限、未配中转、分块失败）只能
`visual_gap`，帧数据量小、任何已配置 AI 环境可达。供应商 `image_input` 能力
（E5）以官方文档核实、真实调用冒烟为独立验收门禁。（`REQ-057`、
`REQ-055`/`REQ-017`/`REQ-052` 修订）
