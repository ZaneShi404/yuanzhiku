# ADR-004：场景感知关键帧采样策略

状态：接受。

均等间隔采样存在边界跳变、首尾永不覆盖、短视频只抽单帧、黑帧未经检查即入库等问题，且采样参数不可追溯。决定采用场景感知混合策略：ffmpeg 场景检测（阈值 0.3）输出候选点，等间隔槽位在半个槽距容差内吸附最近未使用场景点，吸不到保留等间隔位置；首末槽锚定约 5%/95%，短视频（<120s）至少 3 帧，长视频按 120 秒密度并受 video_max_frames 封顶；黑帧（灰度均值 <16）拒绝并按候选序列（未使用场景点、±5% 平移）重试。每帧持久化采样来源 reason（scene/even，数据库 schema v8）与真实像素宽高，采样参数全量进入 `config_hash`（`ffmpeg-local:2:…`）。后果：采样身份与参数可追溯，参数变更生成新分析身份而不静默污染证据链。（`REQ-016`、`REQ-053`）
