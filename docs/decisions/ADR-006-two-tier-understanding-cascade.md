# ADR-006：两层级联理解与完整性判断约束

状态：**被取代**（v1.5，2026-08-16 用户裁定：彻底移除关键帧视觉路径，见
[ADR-011-video-direct-multimodal.md](ADR-011-video-direct-multimodal.md)；
完整性判断机制与阈值保持不变）。

原决定（存档）：纯转写摘要会遗漏仅以画面呈现的信息（产品名、演示步骤、图表、画面文字），而全量逐帧理解成本高。决定采用两层级联：先以确定性规则（转写覆盖率 <0.5 字符/秒或最长静音超过 30% 时长直接判疑似不完整，不消耗 LLM 调用）加约束 JSON 的 LLM 判定（`likely_incomplete` 且置信度 ≥0.6 才成立）评估完整性；完整走 tier1 纯文本摘要，疑似不完整或 `force_tier2` 走 tier2——逐帧画面理解（强制画面文字提取）后增强摘要；tier2 需 vision_model 已配置，需要而不可用时在摘要中标记 visual_gap。AI 建议的领域/体裁强制收敛到分类清单（标签自由），仅以标记嵌入摘要文本，经用户显式保存元数据才采纳；AI 作业失败/取消不降低已完成视频版本状态。后果：成本与覆盖按需分层，判定方式（规则/LLM 与置信度）随摘要持久化，可审计、可复现。（`REQ-051`、`REQ-016`、`REQ-033a`）

v1.5 取代说明：tier2 关键帧视觉路径整体移除（vision_model 设置与 describe_frames 接口删除）；画面信息补充改由 `REQ-055` 视频直送承担（多模态模型直接产出补充转写/理解+摘要+建议分类），直送不可行/失败时 tier1 摘要 + visual_gap 标记。
