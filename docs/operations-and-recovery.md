# 运维与恢复

通过 `scripts/start-windows.ps1` 启动，默认仅监听 `127.0.0.1`。日常启动可双击桌面「源知库」快捷方式或根目录 `启动源知库.cmd`，两者均调用该脚本；快捷方式缺失时运行 `scripts/install-desktop-shortcut.ps1` 重建。启动时获取 `<data-root>/state/instance.lock` 排他锁；已有实例不会启动第二个服务（`REQ-002`）。可用 `YUANZHIKU_DATA_ROOT` 覆盖数据根。首次无 `-Port` 启动会选择 `8765..8865` 中可用端口并写入 `<data-root>/state/port.json`；显式 `-Port` 会在确认该端口可用后替换该数据根的保存偏好。后续无 `-Port` 启动仅重用保存端口。若保存端口已由同一数据根的服务监听，启动器打开该服务；若端口被其他进程占用或已不可绑定，启动明确失败且不改写 `port.json`。`YUANZHIKU_DATABASE_URL` 未设置时使用 SQLite。显式 SQLite URL 使用 `sqlite://`；PostgreSQL 使用 `postgresql://`、`postgres://` 或 SQLAlchemy driver URL（例如 Compose 的 `postgresql+psycopg://...`）。所有 PostgreSQL URL 都进入 PostgreSQL repository；常规 API/worker 只检查 Alembic revision 已达到镜像 head，未就绪、连接、driver 或配置错误都会明确失败，绝不回落或伪装为 SQLite。Compose 仅由一次性 `migrate` 服务执行 schema upgrade，API/worker 依赖其成功完成。

每日首次成功启动入队一次低优先级 backup；备份在 `<data-root>/backups`，成功后保留最近 30 个日期项。SQLite 备份含一致的 SQLite 副本、逻辑记录和 artifact；PostgreSQL 备份含经事务读取的逻辑记录、`backups` catalog 记录和 artifact。两者都有 SHA-256 清单，不含模型、staging 或日志正文（`REQ-040`）。

还原 API 要求 `target_data_root` 不存在或为空且不同于当前根；因此不会覆盖当前库。PostgreSQL 逻辑备份还原还必须提供一个独立、无任何表的 PostgreSQL `target_database_url`：先完成归档验证和空目标检查，再对该目标显式迁移到 head，最后写入还原记录；不会降级写入 SQLite。缺失表或结构无效的完整备份记录会在接触目标前被拒绝。导出前由 UI 显式传递 `confirmed: true`；导出和 reimport 保持可移植业务记录，不包含或重建本地 `backups` catalog。reimport 将在写入前验证 zip、manifest、hash、关系和 ID 链冲突（`REQ-041`）。`/api/v1/verify` 提供完整或抽样 hash 校验（`REQ-042`）。

本地视频分析要求 `ffmpeg` 和 `ffprobe` 可由服务进程找到，或通过 `YUANZHIKU_FFMPEG_BIN`、`YUANZHIKU_FFPROBE_BIN` 明确指定。`GET /api/v1/capabilities` 的 `media.local` 显示二进制可用性；工具缺失时视频导入仍成功保存原件，但分析作业为 `blocked`，安装工具后可从作业页重试。视频总超时、内存、staging 磁盘、最大关键帧在设置页和 `/settings` 配置。日常备份、导出、还原与再导入都包含并校验原视频及受引用的关键帧 artifact、视频分析和帧关系；永久删除来源时只清理无引用的原件和关键帧。

链接下载（`video_download` 作业）在 yt-dlp 或 FFmpeg 缺失时明确 `blocked`（`/capabilities` 的 `downloader.enabled=false`，`POST /videos/link` 返回 `503`）；因反爬、链接失效、平台拒绝等外部原因失败时为 `failed` 且可有限重试（作业页重试按钮），绝不静默切换来源或平台。下载总超时、无进展观察窗口、staging 磁盘上限在设置页与 `/settings` 配置（`download_timeout_seconds`、`download_no_progress_seconds`、`download_disk_limit_mb`）。回环过滤代理仅监听 127.0.0.1 随机端口、仅存活于单个下载作业生命周期，作业结束（无论成败）即关闭，无长驻端口。`data/state/download/cookies/` 按平台存放用户显式导入的 cookies.txt（`<platform>.txt`，每平台 1MB 上限，同平台重复导入覆盖）；下载与探测按链接平台自动选用对应文件；删除该平台文件或调用 `DELETE /settings/download-cookies/{platform}` 即彻底移除。遗留单文件 `cookies.txt` 启动时按注册域分拣迁移到平台文件并删除旧文件。备份、导出与 reimport 显式排除 `data/state/download` 路径（manifest `exclusions` 含 `state/download`），Cookie 内容绝不进入备份快照、导出 ZIP 或再导入；作业内 Cookie 拷贝随 per-job staging 作业结束即清理。

媒体 AI 为两个相互独立的配置分组（设置页或 `PUT /api/v1/settings/ai`）：语音转写（`provider`/`base_url`/`model`/API key）与理解摘要（`provider`/`base_url`/`chat_model`/API key，纯文本）。`provider` 取 `off` 或 `openai_compatible`；`base_url` 留空表示提供方默认端点，非空必须是 HTTPS 公网地址（无 userinfo、≤2048 字符）；`api_key` 提交空串或省略不触碰既有凭据，非空则原子写入 `<data-root>/state/ai/credentials.json`，该文件绝不进入数据库、备份、导出或日志，API 仅回显掩码提示。凭据文件与按平台 Cookie 文件及所在目录（`state/ai`、`state/download/cookies`）在启动与写入时收紧为仅当前账户、SYSTEM 与 Administrators 可访问（Windows 断开 ACL 继承，POSIX 0600/0700）。配置与凭据每次调用时惰性读取，改动即时生效、无需重启；凭据文件**缺失**按首次配置处理（空字典）；**损坏**（JSON/类型非法）时所有读取凭据的端点返回 `503 credential_store_corrupt`（中文提示恢复方式），绝不覆盖或删除原文件——手动修复或删除该文件即可恢复。两个配置示例：① 同一提供方同一 key——以阿里云百炼 OpenAI 兼容模式为例，两组 `base_url` 均填 `https://dashscope.aliyuncs.com/compatible-mode/v1`、同一 key，转写 `model` 填该端点支持的转写模型名（缺省 `whisper-1`），理解 `chat_model` 填 `qwen-plus`（画面补充由视频直送的 `video_qwen` 凭据与多模态模型承担，见下文「视频直送」）；② 分组异构——转写组用 Groq（`base_url` 填 `https://api.groq.com/openai/v1`，`model` 填 `whisper-large-v3`，key 为 Groq key），理解组用国内提供方端点（如上述百炼地址与 `qwen-plus`）；未配置视频直送时，完整性判定认为需要画面补充而无法直送则摘要标记 `visual_gap`，摘要本身仍按 tier1 产出。模型名以提供方当前文档为准。关键帧采样密度固定为 120 秒/帧：目标帧数为 `ceil(时长/120)`，短视频（<120s）至少 3 帧，两者均受 `video_max_frames`（1..32，默认 12）封顶；调大上限只在足够时长下增加帧数，且因采样参数进入 `config_hash`，变更后新分析构成新身份、旧分析保留可查。图片分析断路器使用独立设置键 `image_timeout_seconds`/`image_memory_limit_mb`/`image_disk_limit_mb`（缺省分别为 3600/2048/1024，与视频断路器一致，可在设置页"本地图片分析"分组单独调整）。排障：转写/摘要作业 `blocked`「未配置媒体 AI 服务」表示对应分组未启用或缺 key，检查组开关并保存凭据；`POST /settings/ai/test` 的失败消息已脱敏——「鉴权失败」检查 key、「网络不可达或连接超时」检查网络与端点、「端点无效或模型不可用」检查 base_url 与模型名；摘要作业 `failed`「请先完成语音转写」时先成功执行一次转写；迁移到新数据根（还原/再导入）后需重新填写 API key（凭据不随备份/导出携带）。自动流水线总开关 `ai_auto_pipeline`（默认开；设置页"媒体 AI"区的"自动流水线"勾选或 `PUT /settings/ai` 的 `auto_pipeline` 字段，关闭即不再自动串联，手动触发转写/摘要不受影响）：开启且对应分组已配置时，视频分析成功自动串联转写→摘要，文档/粘贴解析成功自动入队 `source_classify` 分类作业——正文截断至前 8000 字符发往所配置理解组端点（属出网行为，出局面与转写/摘要相同，不需要时关闭开关或将理解组置 `off`）；图片不分类。AI 建议按只填空缺规则自动写入来源元数据（领域/体裁仅在为空时写入、标签并集合并、用户已填字段绝不覆盖），用户可随时在"编辑元数据"中修改；实际写入会记 `ai_classify_applied` 审计事件（仅字段与数量）。

操作日志只记录事件类型、ID、结果和时间，按日保留 30 天，不写正文、路径、令牌或请求体（`REQ-003`, `REQ-042`）。任何运行、恢复或排障步骤都不得获取来源 URL、调用网页视频平台或以程序方式处理抖音；外部卡始终只保留用户输入的元数据。


本地转写（v1.5，`REQ-054`）：转写路径策略 `ai_transcriber_engine`（auto/local/api，默认 auto，设置页「本地转写」区）——auto 本地优先、本地不可用或转写失败自动降级 API 转写（作业消息注明「本地转写不可用，已使用 API 转写」，表示的 parser_name/config_hash 记录引擎与降级事实）；无任何可用路径时作业 blocked「未配置任何可用转写路径：请下载本地转写模型或配置转写 API」。本地模型经 `POST /settings/ai/stt-model`（action=download/delete）管理：download 入 `stt_model_download` 作业异步执行（单 worker、失败可重试、409 防重复），delete 同步幂等；模型文件位于 `data/models/stt/`，不进入备份/导出/reimport（归档只白名单写入 `state/knowledge.db`、`records.json`、manifest 与 artifacts，`data/models` 天然不入档）；下载/删除写审计事件。模型缺失或损坏时按路径策略降级或 blocked，重下即可。

视频直送（v1.5，`REQ-055`）：完整性判定「可能缺失」后按两级补充理解执行（用户裁定 2026-08-16）——视频直送（`ai_video_provider` = qwen/mimo，多模态模型直接产出补充转写/理解+摘要+建议分类）→ 直送不可行/失败时 tier1 摘要 + visual_gap 标记；直送字节仅发往用户显式配置端点（含 DashScope 临时上传主机与自备中转地址，均经 HTTPS/公网/无 userinfo 校验），摘要标记含 `video_direct`/降级原因。自备中转（决策 22）有两种形态：`ai_video_relay_kind = http | cos`（默认 http）。http 形态部署于用户云服务器（`tools/video-relay/` Docker compose 交付物，需已备案域名）——上传 Bearer 密钥、64 位 hex 随机 token、TTL 默认 30 分钟后台清理、无目录列举/路径穿越、默认 300MB 上限，仅回环监听、HTTPS 由前置 OpenResty/nginx 终结；配置 `ai_video_relay_base_url` + 中转密钥后直送优先经中转 URL。cos 形态（未备案环境）：配置 `ai_video_cos_bucket`/`ai_video_cos_region` + `cos_secret_id`/`cos_secret_key` 凭据（凭据文件纪律同 REQ-052），上传对象至 `video-relay/<随机>/<文件名>`、以 30 分钟预签名 URL 交供应商拉取、拉取后尽力删除对象（桶生命周期规则兜底）；COS 默认域名属腾讯已备案域名，不受未备案拦截。中转停用即链路自动回退供应商原路径，无阻塞。

部署状态实录（2026-08-17，无密钥版）：用户中转已按 cos 形态配置生效——腾讯云 COS 桶（ap-shanghai，私有读写，预签名 URL 拉取 + 拉取后删除），上传/拉取/清理闭环实测通过。http 形态部署物保留在用户云服务器 `/opt/yzk-video-relay`（备用）：用户 DDNS 域名 ddns-example.invalid（花生壳，归属 Oray、无法备案）实测被腾讯云未备案拦截（DNS 拦截页 + 回源 302 webblock + Cloudflare 回源 443 ClientHello 被 RST），已确认该域名不可用于中转；日后用户获得已备案域名可切回 http 形态。全部密钥仅存本地凭据文件与服务器 `.env`，不进仓库。
