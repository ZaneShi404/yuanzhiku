# 威胁模型

| 风险 | 控制 | 需求 |
|---|---|---|
| 本地数据意外暴露 | 仅 IPv4 loopback；无遥测、HTTPS、远程服务或外部 URL 获取 | REQ-002, REQ-003 |
| 不受信任文档解析 | 流式限制、磁盘阈值、单 worker、超时/无进度断路器、失败保留原件 | REQ-010, REQ-014, REQ-033 |
| 不受信任本地视频 | 仅 MP4/WebM、本地 FFmpeg/ffprobe 无 shell 子进程、独立 staging、总超时/内存/磁盘/帧数断路器、失败保留原件 | REQ-015, REQ-016, REQ-033a |
| 未配置的媒体 AI 或供应商泄露 | 默认双组全关、零网络；提供方必须显式配置（双组独立开关）；凭据仅存 `<data-root>/state/ai/credentials.json`，不进 DB/备份/导出/日志，API 仅回显掩码提示；错误脱敏不含 URL/密钥/响应正文 | REQ-017, REQ-051, REQ-052 |
| AI 出站内容泄露（音频分块、关键帧图片、转写文本、文档/粘贴正文发往外部端点） | base_url 统一校验：仅 HTTPS、公网主机、无 userinfo、≤2048 字符；发送面为用户逐视频显式触发或 `ai_auto_pipeline` 自动串联（默认开，可在设置页或 `PUT /settings/ai` 关闭）；自动分类开启且理解组已配置时文档/粘贴正文（截断至前 8000 字符）也发往所配置端点；默认双组关闭即零出站流量；密钥只存凭据文件，调用错误一律脱敏 | REQ-051, REQ-052 |
| 版权/授权不明 | 导入前权利声明；不保存私密说明；外部卡不构成证据 | REQ-011, REQ-030 |
| 证据篡改 | 内容寻址 artifact、不可变 representation/evidence、hash 与链式外键 | REQ-011, REQ-020 |
| 外部平台合规 | 外部卡没有 HTTP 请求逻辑；抖音 URL 严格验证/字面保存/仅显式浏览器打开（REQ-031 例外仅限 REQ-047/047a 受限下载通道，外部卡/解析器/检索/导入/AI 端口不受影响） | REQ-030, REQ-031 |
| 恢复覆盖或损坏 | manifest/hash 验证，还原仅新根，导出确认，保留审计 | REQ-040..042 |
| 日志泄露 | 结构化最小事件，禁止内容、路径、凭据、request body | REQ-003, REQ-042 |
| 下载器被恶意/伪造 URL 利用（SSRF、外平台跳转） | 平台白名单 + 严格 URL 校验；yt-dlp 无 shell 子进程、忽略用户配置；出站经作业内回环过滤代理逐连接校验注册域清单、拒绝内网/回环解析目标；显式代理覆盖环境代理；断路器限制资源 | REQ-047 |
| Cookie 泄露或进入分发物 | 平台 cookies.txt 仅存 `data/state/download/cookies/<platform>.txt`、按平台自动选用、逐作业拷贝即删；不进 DB/日志/备份/导出/reimport；UI 按平台显式删除；浏览器 Cookie 库直读已按二次决策整体删除 | REQ-047a, REQ-040..042 |
| 平台反爬、账号风控 | 单 worker、无并发批量、无自动化调度、有限重试；Cookie 由用户自愿导入且可随时删除 | REQ-047, REQ-047a |
| 下载内容不可信（伪造/损坏/超限） | 复用 REQ-015/016 全部断路器与 ffprobe/hash 校验，高度 ≤1080 后置校验；失败保留原状 | REQ-047, REQ-016 |
| 平台条款与版权 | 用户权利声明必填；仅个人本地使用；不绕过 DRM/会员/付费墙；产品不提供分发能力，导出后使用由用户自担；外部卡仍不构成证据 | REQ-011, REQ-030, REQ-047 |
