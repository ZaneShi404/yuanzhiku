# 威胁模型

| 风险 | 控制 | 需求 |
|---|---|---|
| 本地数据意外暴露 | 仅 IPv4 loopback；无遥测、HTTPS、远程服务或外部 URL 获取 | REQ-002, REQ-003 |
| 不受信任文档解析 | 流式限制、磁盘阈值、单 worker、超时/无进度断路器、失败保留原件 | REQ-010, REQ-014, REQ-033 |
| 版权/授权不明 | 导入前权利声明；不保存私密说明；外部卡不构成证据 | REQ-011, REQ-030 |
| 证据篡改 | 内容寻址 artifact、不可变 representation/evidence、hash 与链式外键 | REQ-011, REQ-020 |
| 外部平台合规 | 外部卡没有 HTTP 请求逻辑；抖音 URL 严格验证/字面保存/仅显式浏览器打开 | REQ-030, REQ-031 |
| 恢复覆盖或损坏 | manifest/hash 验证，还原仅新根，导出确认，保留审计 | REQ-040..042 |
| 日志泄露 | 结构化最小事件，禁止内容、路径、凭据、request body | REQ-003, REQ-042 |
