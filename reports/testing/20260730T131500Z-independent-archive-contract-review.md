# 20260730 独立归档契约复核记录

## 范围

本记录固化对工作树中 V1 过程档案政策、构建器、独立验证器、来源登记和归档回归的只读复核结论。复核未运行构建或测试，未访问日常 `data/`，未读取或修改已封存的档案目录及 ZIP。

## 已确认的边界

- T1 `source_run_id` 已由白名单传播到来源清单和证据登记，并由独立验证器交叉核对。
- 来源 SHA-256 保留在来源清单；白名单和证据登记的用途可以交叉核对。
- 归档单元测试以运行时拼接方式构造合成 URL userinfo，T0 副本可保留该测试源码的字节语义。
- `DEF-ARCH-004`、`DEF-ARCH-005` 和 `DEF-ARCH-006` 在工作树账本生成逻辑中保持待独立验收状态，不提前声明关闭。

## 结论

复核时未发现必然导致单进程新档案构建或独立验证立即失败的静态问题，但以上三项属于档案边界与不可变性风险，必须在生成下一后继快照前完成修复并获得新的独立测试和验收结论。

真实 PostgreSQL 迁移/还原、物理 Docker Compose 拓扑以及 Edge 和 Chrome 黑盒 GUI 验收仍不在本次复核范围内，继续保持 `blocked`。
