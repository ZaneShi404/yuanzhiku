## 1. 审核范围

本次门禁针对决策 11（douyin 组注册域清单增补 `365yg.com`）做四项核验：

1. 规范证据链：7.2.1 注册域表格新行、决策 11 文本、修订记录条目，及登记粒度是否恰当；
2. 实现：注册表增补与主机名匹配逻辑（label 边界）是否对该域生效、有无超范围放行；
3. 测试：新增用例是否真断言（正例/负例边界）；
4. 安全评估：整域（含全部子域）登记 `365yg.com` 的残余风险在"注册域主机名白名单 + 单用户本地"威胁模型下是否可接受。

## 2. 核验结论（逐项）

- 决策 7 原文（`docs/v1-2-requirements.md:423`）保留 08-13 拍板时的 douyin 组四域清单未做改写：符合仓库"决策原文不覆盖、以追加方式修订"的既有纪律（决策 1 二次决策先例），决策 11 以追加方式生效，无矛盾。

- 登记粒度：登记整域 `365yg.com`（含全部子域），与既有清单粒度一致（bilibili 组的 `bilivideo.com`、douyin 组的 `douyinvod.com` 同为整域登记）。登记为 douyin 平台组而非新增平台组，语义正确（出站域按平台归组，URL 层校验不接受该域作为入口）。
- 结论：证据链实质完整、粒度恰当。**不足**：实测证据仅以规范内嵌引述存在，仓库内无独立归档的测量记录（见 finding F-1）。

### 2.2 实现（commit 606823e）

- 变更内容：`DOWNLOAD_REGISTRY["douyin"]` 增补 `"365yg.com"` 并附决策注释（`backend/app/adapters/downloader.py:46-50`）。全仓库检索确认注册表仅此一处为唯一来源（无其他代码/文档副本），生产路径为 `registered_domains(platform)` → `_default_proxy_factory` → `LoopbackFilterProxy(registered_domains(platform))`（`downloader.py:437-438,565,575`），增补即生效于作业实际出站控制。
- 主机名匹配逻辑（`downloader.py:72-81`）：小写化、去尾点后按 label 边界匹配——`host == domain` 或 `host.endswith("." + domain)`；含 `:` 的主机名（IPv6 括号形式）直接不命中；`_validate_host`（`downloader.py:217-227`）先拒 IP 字面量（IPv4 也经 ipaddress 判字面量后拒绝）。CONNECT 与明文 HTTP Host 两条路径均经过同一 `_validate_host`，重定向链逐连接复校验，fail-closed 语义不受影响。
- 边界行为独立复算（运行模块函数逐例验证）：
  - 应放行且放行：`365yg.com`（apex）、`v95-aw-default.365yg.com`（实测主机名）、`a1.365yg.com`、任意子域形式、大小写混合（`V95-AW-DEFAULT.365YG.COM`）、尾点形式（`365yg.com.`）；
  - 应拒绝且拒绝：`evil365yg.com`（无 label 边界的拼接冒充）、`365yg.com.evil.com`（后缀冒充）、`sub.evil365yg.com`、`365ygg.com`、`127.0.0.1`、`[::1]`。
  - 注：`evil.365yg.com` 这类带 label 边界的子域会命中——这是整域登记的设计语义（该域全部子域放行），非绕过，与 2.4 安全评估对应。
- 结论：匹配逻辑对该域正确生效，无超范围放行（放行集严格限定于注册域自身及其 label 边界内子域）。

### 2.3 测试（新增用例）

### 2.4 安全评估：整域登记 365yg.com 的残余风险

- 域归属核实：`365yg.com` 为字节跳动媒体 CDN 域（抖音/今日头条/西瓜等字节系产品共用），实测主机名 `v95-aw-default.365yg.com` 与抖音 aweme 系 CDN 命名模式一致；决策 11"字节跳动媒体 CDN 域，非第三方"的归属判断成立。
- 整域登记（任何该域子域可通过代理）的残余风险，在既定威胁模型下逐项评估：
  - 单用户本地、仅用户显式提交的链接触发下载，出站请求集由用户提交链接派生，无批量/自动化/共享面；
  - 代理保持 fail-closed：每新连接重校验注册域、拒绝 IP 字面量与回环/内网/保留段（隧道段例外受"主机名已过注册域校验"门控，`downloader.py:235-250`）、resolve-then-connect 且连接后对端复核——即使恶意子域内容诱导跳转，逐连接校验使重定向无法触达未登记域或内网目标；
  - 下载产物经 ffprobe 校验（合法 MP4/WebM、时长、高度 ≤1080）、≤2GB、内容寻址不可变、不执行——恶意子域只能影响下载内容本身，破坏面与正常 CDN 内容等价；
  - 子域粒度不构成额外安全边界：CDN 主机名为机器生成数据且频繁轮换，逐子域登记不可维护并会制造持续漂移故障；安全边界是"注册域"，而非主机名。
- 跨产品共用域说明：该域同时服务字节系其他产品，登记意味着作业理论上可接触同属字节跳动第一方的其他 CDN 内容，但不引入任何第三方域；可接受。
- 结论：整域登记的残余风险在本仓库声明的威胁模型（`REQ-002` loopback、单用户本地、无上游恶意 DNS 假设）下可接受；逐子域登记的替代方案既不现实也不增益。

## 3. Findings

- **F-1（Low）实测证据未独立归档**。决策 11 的实测证据仅存在于规范内嵌引述（7.2.1 表格行、决策 11、修订记录），仓库内无独立日期的测量记录（无出站域抓取明细、无 denied→登记→复验的代理计数记录、未注明实测所用锁定版本）。7.2.1 维护规则要求清单变更"附实测证据"，内嵌引述由开发角色自述，独立复核无法对原始抓取交叉验证。
  建议（冻结门禁前完成）：在 T-VID-005 验收登记中追加 2026-08-14 抖音复验附记，或另建 dated 记录，至少登记：锁定版本（现锁 `yt-dlp==2026.7.4`）、实测出站域抓取（含 `v95-aw-default.365yg.com` 及当次全部出站主机）、登记后复验"全部出站 ⊆ 注册表"的断言结果。不改变任何受审文件。
- **F-2（Info）新用例边界断言可补全**。建议顺手补 apex `365yg.com`、大小写与尾点归一两条断言，与既有通用用例形成对称覆盖（可选，不构成门禁条件）。

## 4. 最终裁定

- 条件：冻结门禁前完成 F-1 的证据归档补充（低成本、不触碰受审代码与规范）；F-2 为可选改进，不构成条件。
